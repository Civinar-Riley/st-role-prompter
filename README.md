# 角色名注入

给 SillyTavern（酒馆）用的角色名速查注入工具：**点一下条目，预设消息直接进输入框，光标停在该停的地方。**

当"导演"的时候经常要手打角色名，记不住、打字又慢。这个小工具把常用的「标题 + 描述 + 注入内容」存成条目，点一下就注入到酒馆输入框——比如点「徐渭」，输入框里直接出现 `徐渭：“”`，光标稳稳落在两个引号中间，接着打字就行。

## 核心设计

### 条目 = 三段式

| 字段 | 作用 | 示例 |
| --- | --- | --- |
| 标题 | 给你看：这是什么 | `徐渭` |
| 描述 | 给你看：更具体些 | `{{user}}，冷漠剑客` |
| 注入内容 | 进输入框的东西 | `徐渭：“\|”` |

`|` 是光标标记，写在注入内容里想落光标的位置，注入时会被移除。

### 双池存储（解决"条目越堆越多"）

- **本卡池** —— 存角色卡变量，切到哪张卡显示哪张卡的条目。分享角色卡时条目自动跟着走。
- **通用池** —— 存全局变量，跨角色卡通用（自己的人设、反复出现的 NPC）。

面板顶部两个页签切换。

### 批量导入（解决"角色太多不想一个个填"）

- **世界书扫描**：现代角色卡主流写法是设定放世界书，所以角色名要从世界书里找。列出条目名 + 内容摘要供勾选，勾选状态记住，下次只问新增的。
- **批量粘贴**：一行一个名字，粘进去一键生成 N 个条目。

### 形态

可拖动悬浮面板（默认停在输入框上方、位置记忆）+ 脚本按钮 + 可关闭的悬浮球。

## 技术方案

做成**酒馆助手（JS-Slash-Runner）脚本**，原生 JS 单文件 IIFE，零构建零依赖。

核心技术点（已用官方源码核实，见 [`知识库/10`](知识库/10-输入框机制源码核实.md)）：

- 脚本运行在 iframe 中，但 jQuery 是 `window.parent.$`，可直接操作酒馆页面 DOM。
- 注入输入框：`#send_textarea` 改 `value` → `dispatchEvent(new Event('input', {bubbles:true}))` → `focus()` + `setSelectionRange()` 定位光标。**这是 SillyTavern 官方自己在 `/setinput`、`/impersonate`、发送后清空三处用的写法。**
- 酒馆对中文引号（`“ ”`）不做任何处理，Markdown 快捷键默认关闭——"光标停在引号中间"必须工具自己做。
