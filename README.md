# 角色名注入

给 SillyTavern（酒馆）用的角色名速查注入工具：**点一下条目，预设消息直接进输入框，光标停在该停的地方。**

当"导演"的时候经常要手打角色名，记不住、打字又慢。这个小工具把常用的「角色名 + 一句话描述 + 预设消息模板」存成条目，点一下就注入到酒馆输入框——比如点「徐渭」，输入框里直接出现 `徐渭：“”`，光标稳稳落在两个引号中间，接着打字就行。

## 需求描述

| 项 | 内容 |
| --- | --- |
| 形态 | 悬浮窗（可拖动悬浮球 + 管理面板） |
| 入口 | 酒馆助手脚本按钮；可选输入框旁的按钮 |
| 条目 | 角色名、小字描述、预设消息模板 |
| 点击行为 | 把预设消息注入酒馆输入框，光标定位到模板中标记的位置 |
| 数据管理 | 手动增删改条目，支持分组、搜索、排序 |
| 持久化 | 跟随用户存档，支持导出/导入 JSON |

**示例条目**

| 字段 | 值 |
| --- | --- |
| 角色名 | 徐渭 |
| 描述 | `{{user}}`，冷漠剑客 |
| 预设消息 | `徐渭：“|”` → 注入后为 `徐渭：“”`，光标在 `“` 和 `”` 之间 |

`|` 是光标标记，写在模板里想落光标的位置，注入时会被移除。

## 技术方案

做成**酒馆助手（JS-Slash-Runner）脚本**，不做原生插件。理由：

1. 需求是"常驻悬浮窗 + 操作输入框"，不属于任何消息楼层，脚本形态天然合适。
2. 不需要跨版本维护酒馆内部模块 import，比原生插件稳定。
3. 分发简单：一个 JSON 文件，用户导入酒馆助手即可。

核心技术点：

- 脚本运行在 iframe 中，但 jQuery 是 `window.parent.$`，可直接操作酒馆页面 DOM。
- 注入输入框：`#send_textarea` 改 `value` → `dispatchEvent(new Event('input', {bubbles:true}))` → `focus()` + `setSelectionRange()` 定位光标。
- 条目数据存酒馆助手全局变量 `{type: 'global'}`，跟随用户存档。

详见 [`知识库/03-输入框注入方案.md`](知识库/03-输入框注入方案.md) 与 [`设计文档.md`](设计文档.md)。
