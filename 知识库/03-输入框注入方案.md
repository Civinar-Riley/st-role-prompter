# 03 输入框注入方案（本项目核心）

> 需求：点击条目后把预设消息（如 `徐渭：“”`）注入酒馆输入框，并把光标停在引号中间。

## 一、结论先行

**没有官方 API 能做"设置输入框文本 + 指定光标位置"**。已核对的全部资料（酒馆助手官方文档 66 篇、`@types` 全量类型定义、STscript 命令手册）里：

- STscript 有 `/setinput <文本>`，能设置输入框内容，但**无法指定光标位置**，且文本里的换行会打断命令解析。
- 酒馆助手没有任何 `setInputText()` 之类的封装。

所以方案是**直接操作 DOM**。脚本里的 jQuery 就是酒馆主页面的 `$`，可以直接选中输入框。

## 二、输入框的真实身份

| 项 | 值 |
| --- | --- |
| 选择器 | `#send_textarea` |
| 元素类型 | `<textarea>` |
| 所在位置 | 酒馆主页面（不是脚本 iframe 内） |

```javascript
// 脚本内拿元素（两种等价写法）
const ta = $('#send_textarea')[0];                 // jQuery 直接作用于酒馆页面
const ta2 = window.parent.document.querySelector('#send_textarea');
```

> 如果未来酒馆版本改了 id，用 DevTools 在输入框上右键 → 检查，确认最新 id 后替换即可。

## 三、注入的完整实现

### 3.1 最小可用版（社区/资料里流传的 `fillInput`）

```javascript
function fillInput(text) {
  try {
    const textarea = document.querySelector('#send_textarea') ||
                     (window.parent && window.parent.document.querySelector('#send_textarea'));
    if (textarea) {
      textarea.value = text;
      textarea.dispatchEvent(new Event('input', { bubbles: true }));
      textarea.focus();
    }
  } catch (e) { console.error(e); }
}
```

### 3.2 本项目采用的完整版（支持光标定位 + 替换选中文本 + 追加模式）

```javascript
const CURSOR_MARK = '\u0000';   // 用不可见字符标记光标落点，最后再删掉

/**
 * 把文本注入酒馆输入框
 * @param {string} text     要注入的文本
 * @param {object} opts
 *   - cursor: number        光标落点（字符下标）。不传则光标停在文本末尾
 *   - mode: 'replace'|'append'|'cursor'  替换全部 / 追加到末尾 / 插入到当前光标处（默认 append）
 *   - mark: string          文本中的光标标记，如 '|'；命中时优先用它定位，并从最终文本里移除
 * @returns {boolean} 是否成功
 */
function injectToInputBox(text, opts = {}) {
  const host = window.parent && window.parent !== window ? window.parent : window;
  const doc = host.document;
  const ta = doc.querySelector('#send_textarea');
  if (!ta) return false;

  const mode = opts.mode || 'append';
  const old = ta.value || '';
  const selStart = ta.selectionStart ?? old.length;
  const selEnd = ta.selectionEnd ?? old.length;

  // 决定拼接后的完整文本，并记录注入片段在完整文本里的起点
  let next, injectStart;
  if (mode === 'replace') {
    next = text;
    injectStart = 0;
  } else if (mode === 'cursor') {
    next = old.slice(0, selStart) + text + old.slice(selEnd);
    injectStart = selStart;
  } else { // append
    next = old ? old.replace(/\s+$/, '') + '\n' + text : text;
    injectStart = next.length - text.length;
  }

  // 计算光标落点：优先用文本内标记，其次用显式 cursor 参数，最后落在末尾
  let cursor = -1;
  if (opts.mark && text.includes(opts.mark)) {
    const idx = text.indexOf(opts.mark);
    next = next.slice(0, injectStart + idx) + next.slice(injectStart + idx + opts.mark.length);
    cursor = injectStart + idx;
  } else if (typeof opts.cursor === 'number') {
    cursor = injectStart + opts.cursor;
  }
  if (cursor < 0 || cursor > next.length) cursor = injectStart + text.replace(opts.mark || '', '').length;

  // 写入 + 通知酒馆 + 定位光标
  ta.value = next;
  ta.dispatchEvent(new Event('input', { bubbles: true }));   // 必须！否则酒馆内部状态不更新
  ta.focus();
  try { ta.setSelectionRange(cursor, cursor); } catch (e) { /* 非 textarea 元素会抛错 */ }
  ta.dispatchEvent(new Event('select', { bubbles: true }));

  return true;
}
```

用法：

```javascript
// 注入 徐渭：“” 并把光标停在两个引号中间
injectToInputBox('徐渭：“”', { mark: '|' });        // 写法 A：模板里写 徐渭：“|”
injectToInputBox('徐渭：“”', { cursor: 4 });        // 写法 B：显式下标（徐=0 渭=1 ：=2 “=3 ”=4）
injectToInputBox('徐渭：“”', { mode: 'replace' });  // 清空输入框再注入
```

### 3.3 为什么必须 dispatch input 事件

酒馆内部维护了输入框的副本状态（用于自动补全、发送校验、高度自适应、消息保存）。只改 `value` 不派发事件，会出现：输入框看起来有内容但酒馆认为它是空的、点发送发不出去、高度不刷新。`dispatchEvent(new Event('input', { bubbles: true }))` 是让酒馆同步的唯一手段。

### 3.4 光标定位要点

- `setSelectionRange(start, end)` 是标准 DOM API，**会自动把焦点给到元素**，所以调用后光标就落在指定位置。
- 顺序建议：先 `focus()` 再 `setSelectionRange()`，最后补一个 `select` 事件。
- 若目标元素不是 `<textarea>`（理论上不会是，但防一手），`setSelectionRange` 会抛错，用 `try/catch` 包住。
- **标记法最稳**：在模板文本里直接写一个占位符（如 `|`），注入时用它算下标再删掉。这样用户改模板时不需要自己数光标位置。

## 四、宏替换

预设消息里允许写酒馆宏，注入前替换：

```javascript
const finalText = substitudeMacros(presetText);
// {{user}}   → 当前用户人设名
// {{char}}   → 当前角色卡名
// {{date}} / {{time}} / {{lastMessageId}} 等
```

注意：宏替换会改变文本长度，**必须在替换之后再计算光标下标**。

## 五、面板焦点问题

悬浮窗 / 弹窗里的按钮被点击时，焦点会跑到面板上，导致注入后光标不在输入框。两个处理：

1. 注入函数里显式 `ta.focus()` + `setSelectionRange()`（上面的实现已经做了）。
2. 面板的容器上阻止默认的焦点抢占：

```javascript
panel.addEventListener('mousedown', (e) => {
  // 让点击面板不夺走输入框焦点（可选，看交互设计）
  if (e.target.closest('input, textarea, [contenteditable]')) return;
  e.preventDefault();
});
```

> 第 2 条有副作用：`preventDefault` 会阻止面板内文本被选中。若面板里需要选中/复制文字，就不要加，只靠第 1 条。

## 六、备选方案：STscript `/setinput`

```javascript
await triggerSlash('/setinput 徐渭：“”');
```

| 优点 | 缺点 |
| --- | --- |
| 走酒馆官方通道，理论上最稳 | **无法控制光标位置** |
| 一行搞定 | 文本含换行 / `|` 会破坏命令解析，需要转义 |
| | 命令写错没有任何反馈，排查困难 |
| | 多行文本注入基本不可用 |

**结论：本项目的核心场景（多行预设 + 光标定位）必须用 DOM 方案。** `/setinput` 只在"注入单行且不需要光标控制"时可作为降级路径。

## 七、进阶：注入后直接发送

如果某些条目希望"点了就直接发出去"：

```javascript
injectToInputBox(text, { mode: 'replace' });
await triggerSlash('/trigger');       // 触发 AI 生成
```

注意 `/trigger` 会立即开始生成，用户没有机会修改文本，建议只在明确标注"直接发送"的条目上使用。

## 八、验证清单

实现完成后逐条手工验证：

- [ ] 输入框为空时点击条目，文本正确注入，光标停在预期位置
- [ ] 输入框已有内容时点击条目，按设计追加/替换
- [ ] 输入框里有选中文本时（mode: 'cursor'），选中的部分被替换
- [ ] 注入后按发送键，消息能正常发出（证明 input 事件生效）
- [ ] 注入后输入框高度自适应正常（长文本不会溢出）
- [ ] 预设里含 `{{user}}` 宏时，注入的是替换后的用户名
- [ ] 手机端（触屏）点击条目同样生效
