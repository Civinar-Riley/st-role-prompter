# 06 酒馆命令手册速查（STscript）

命令通过 `triggerSlash()` 执行：

```javascript
await triggerSlash('/echo severity=success 运行成功!');
const lastId = await triggerSlash('/pass {{lastMessageId}}');
await triggerSlash('/send 推进剧情 | /trigger');
```

**警告**：命令写错不会有任何反馈（`triggerSlash` 可能静默返回 undefined），命令出错会 throw。不要凭记忆编命令，拿不准就查手册。

---

## 一、语法基础

- **管道** `|`：上一条命令的输出传给下一条，用 `{{pipe}}` 取。
- **`||`**：阻止结果自动注入下一条命令。
- **命名参数**：`key=value`，如 `/echo severity=warning 文本`。
- **closure**：`{:` 和 `:}` 包裹，延迟求值，用于 `/if`、`/while` 等。
- **数据类型**：Number、boolean、String、Varname、List、Dictionary、Subcommand、closure。
- **命令别名**：如 `/sendas` 和 `/sys` 等，各有多种写法。

## 二、常用命令速查

### 数据交互（第 1 类）

| 命令 | 作用 |
| --- | --- |
| `/setinput (文本)` | **将用户输入框设置为指定文本**，并通过管道传给下一条命令 |
| `/input default="值" 标题` | 弹窗让用户输入，返回输入内容 |
| `/popup [wide] [okButton="OK"] 文本` | 阻塞式弹窗，支持 HTML |
| `/buttons labels=["A","B"] 提示` | 弹窗给按钮，返回所点项 |
| `/echo [severity=warning] [timeout=4000] 文本` | Toast 提示 |
| `/pass 值` | 把值传给管道 |
| `/abort` | 中止命令队列 |

### 变量

| 命令 | 作用 |
| --- | --- |
| `/setvar key=名 index=0 value` | 设局部变量（聊天元数据），index 可写数组/对象 |
| `/getvar key=名` | 取值 → 管道；宏写法 `{{getvar::名}}` |
| `/setglobalvar key=名 value` | 设全局变量（存进 settings.json） |
| `/getglobalvar key=名` | 取全局变量 |
| `/incvar` `/decvar` | 数值自增自减 |

### 消息与生成

| 命令 | 作用 |
| --- | --- |
| `/send [compact=true] [at=号] [name=名] (文本)` | 添加用户消息，**不触发生成** |
| `/sendas name=角色名 (文本)` | 以指定角色名发消息。**有正文丢失 bug，改用 `createChatMessages()`** |
| `/sys (文本)` | 添加系统消息 |
| `/trigger [await=true] (号或名)?` | 触发 AI 生成 |
| `/stop` | 停止生成 |
| `/hide 号` | 隐藏消息 |
| `/delete 号` | 删除消息 |

### 生成

| 命令 | 作用 |
| --- | --- |
| `/gen [length=200] 提示词` | 用 LLM 生成 → 管道 |
| `/genraw 提示词` | 裸生成（不含角色卡/世界书） |

### 提示词注入

| 命令 | 作用 |
| --- | --- |
| `/inject id=x position=chat depth=4 内容` | 注入提示词，同 id 可覆盖 |

### 文本处理

| 命令 | 作用 |
| --- | --- |
| `/replace find=旧 replace=新 {{pipe}}` | 字符串替换 |
| `/regex find=/pattern/flags replace=新 {{pipe}}` | 正则替换 |
| `/match` `/test` | 匹配 / 测试 |
| `/sort` `/fuzzy` | 排序 / 模糊匹配 |

### 流程控制

| 命令 | 作用 |
| --- | --- |
| `/if left=A right=B rule=eq {:/echo 相等:} else={:/echo 不等:}` | 条件 |
| `/while 条件 {:/...:}` | 循环 |
| `/times 5 {:/echo {{timesIndex}}:}` | 重复 N 次 |

### UI 操控

| 命令 | 作用 |
| --- | --- |
| `/css-var name=--color value=#fff` | 改 CSS 变量（动态主题） |
| `/theme default \| /bubble \| /flat \| /vn \| /panels` | 切换主题样式 |
| `/bg 背景.png` | 设置背景 |
| `/movingui 方案名` | 切换界面布局 |
| `/variableviewer` | 打开变量查看器 |

### 事件

| 命令 | 作用 |
| --- | --- |
| `/event-emit event=名 data=数据` | 发送自定义事件，供酒馆助手脚本 `eventOn` 监听 |

## 三、本项目相关的关键命令

### `/setinput` — 唯一能设置输入框的官方命令

```javascript
await triggerSlash('/setinput 徐渭：“”');
```

限制：

- **不能指定光标位置**。
- 文本含 `|` 会被当作管道，含换行会破坏命令结构。需要转义或改用 DOM 方案。
- 命令写错无反馈。

所以本项目的核心注入走 DOM（见 [03-输入框注入方案.md](03-输入框注入方案.md)），`/setinput` 只作为单行、无光标要求的降级路径。

### `/trigger` — 注入后直接发送

```javascript
await triggerSlash('/trigger');
```

配合 `/send` 可以做"点击即发送"：

```javascript
await triggerSlash('/send 徐渭：“你好” | /trigger');
```

### `/event-emit` — 让快速回复按钮触发脚本

在快速回复里写 `/event-emit event=注入徐渭`，脚本里：

```javascript
eventOn('注入徐渭', () => injectToInputBox('徐渭：“”', { mark: '|' }));
```

这就等于给每个常用角色做了个快速回复按钮，是脚本按钮之外的另一条入口。

## 四、宏（在命令与提示词里可用）

| 宏 | 含义 |
| --- | --- |
| `{{user}}` | 当前用户人设名 |
| `{{char}}` | 当前角色卡名 |
| `{{lastMessageId}}` | 最新楼层 id |
| `{{lastMessage}}` | 最新楼层内容 |
| `{{pipe}}` | 上一条命令的输出 |
| `{{getvar::名}}` | 取局部变量 |
| `{{getglobalvar::名}}` | 取全局变量 |
| `{{get_global_variable::变量}}` | 取酒馆助手全局变量（JSON） |
| `{{format_global_variable::变量}}` | 取酒馆助手全局变量（YAML） |
| `{{get_message_variable::变量}}` | 取楼层变量 |
| `{{date}}` `{{time}}` | 日期 / 时间 |
| `{{input}}` | 用户当前输入框内容 |

在脚本里替换宏用 `substitudeMacros(text)`。
